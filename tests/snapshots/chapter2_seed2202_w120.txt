╭─ 1 of 5 · What a token is ───────────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  Models read text in chunks, not whole words. Each chunk is a token.                                                 │
│  Common words are usually one token. Rare or long words split into pieces.                                           │
│                                                                                                                      │
│  Think of it like: Lego bricks. A common word is one big brick; a rare word takes several small ones.                │
│                                                                                                                      │
│  Example: On OpenAI's public tokenizer, "the" is one token and "antidisestablishmentarianism" is six: ant · idis ·   │
│  est · ablishment · arian · ism.                                                                                     │
│                                                                                                                      │
│  Why a PM cares: Expect names, part numbers and jargon to use more tokens than their word count suggests.            │
│                                                                                                                      │
╰──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯

╭─ 2 of 5 · Why tokens, not words or letters ──────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  A model has a fixed vocabulary of roughly 100K to 200K pieces.                                                      │
│  Whole words plus word pieces cover any text, including typos, names and brand-new words.                            │
│  Letters alone make text long and slow. Whole words alone miss anything new.                                         │
│                                                                                                                      │
│  Think of it like: a phrasebook plus an alphabet. Use a whole phrase when you have one; spell out the rest.          │
│                                                                                                                      │
│  Example: A made-up name like "Zorblax" still works: on OpenAI's public tokenizer it's built from Z · or · bl · ax.  │
│                                                                                                                      │
│  Why a PM cares: The model never rejects odd input. It just spends more tokens on it.                                │
│                                                                                                                      │

╭─ 3 of 5 · Everything is measured in tokens ──────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  Price: dollars per million tokens. Input and output are counted separately.                                         │
│  Speed: tokens per second.                                                                                           │
│  Size limit: how much a model can read at once, also in tokens (Chapter 7).                                          │
│                                                                                                                      │
│  Example: A 2,000-token prompt and a 500-token answer: those two numbers set the cost, the speed and whether it      │
│  fits.                                                                                                               │
│                                                                                                                      │
│  Why a PM cares: Every cost estimate for your product starts with a token count.                                     │
│                                                                                                                      │

╭─ 4 of 5 · The rule of thumb, and its catch ──────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  OpenAI's long-standing rule of thumb: a token is about ¾ of an English word.                                        │
│  The real ratio depends on the tokenizer, the part that cuts text into tokens. Each company and model generation     │
│  has its own.                                                                                                        │
│  OpenAI's newest public tokenizer fits more English into each token. Anthropic's current tokenizer (Claude 4.7 and   │
│  every newer model) fits less, about 0.555 words per token.                                                          │
│                                                                                                                      │
│  Example: By the classic ¾ rule, 1,000 words is about 1,300 tokens. Today's tokenizers range from about 1,100        │
│  (OpenAI) to about 1,800 (Claude), so measure your own text.                                                         │
│                                                                                                                      │
│  Why a PM cares: A tokenizer change is a silent price change: same prompt, same price per token, more tokens.        │
│                                                                                                                      │

╭─ 5 of 5 · What uses more tokens ─────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  Rare words, numbers, code, emoji and many non-English languages split into more pieces.                             │
│  The same sentence can take noticeably more tokens in another language, sometimes about twice as many.               │
│                                                                                                                      │
│  Example: On OpenAI's public tokenizer, "The meeting is moved to Thursday afternoon." is 8 tokens. The same          │
│  sentence in Hindi is 17.                                                                                            │
│                                                                                                                      │
│  Why a PM cares: The same feature can cost more in some languages, so budget per language, not just per user.        │
│                                                                                                                      │
