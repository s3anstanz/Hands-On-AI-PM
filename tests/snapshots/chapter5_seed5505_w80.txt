╭─ 2 of 7 · Quality, speed, cost: pick your balance ───────────────────────────╮
│                                                                              │
│  Bigger models are usually better at hard reasoning and obscure facts. They  │
│  are also slower and pricier.                                                │
│  Per token, Opus costs about 40× as much as Haiku.                           │
│  Smaller models are fast and cheap, and often good enough for simple,        │
│  well-defined jobs.                                                          │
│  You rarely get all three at once.                                           │
│                                                                              │
│  Example: A model that writes excellent legal analysis is wasted on fixing   │
│  typos.                                                                      │
│                                                                              │
│  Why a PM cares: Every model choice gives up some quality, speed or cost.    │
│  Decide which one this job can spare.                                        │
│                                                                              │

╭─ 3 of 7 · Two kinds of speed ────────────────────────────────────────────────╮
│                                                                              │
│  Time to first token: how long before anything appears.                      │
│  Streaming speed: how fast words arrive after that, in tokens per second.    │
│  A model that reasons before answering starts slowly, even if it streams     │
│  fast.                                                                       │
│  Some models sell faster streaming at a higher price.                        │
│                                                                              │
│  Think of it like: waiting for a table vs. how fast the food comes once      │
│  you're seated.                                                              │
│                                                                              │
│  Example: A chat reply is judged on how soon it starts. A report generated   │
│  overnight is judged only on when it's done.                                 │
│                                                                              │
│  Why a PM cares: Find out which one your users feel. Paying to speed up the  │
│  other changes little they notice.                                           │
│                                                                              │

╭─ 4 of 7 · Routing ───────────────────────────────────────────────────────────╮
│                                                                              │
│  Routing sends each request to the model that fits it: easy ones to a small  │
│  model, hard ones to a large one.                                            │
│  In many products most requests are easy, so most traffic can go to the      │
│  cheap model.                                                                │
│  The router can be a simple rule, or a small model that sorts requests       │
│  first.                                                                      │
│                                                                              │
│  Example: A support assistant answers password resets with a small model     │
│  and hands billing disputes to a large one.                                  │
│                                                                              │
│  Why a PM cares: Routing can cut the bill a lot without users noticing, if   │
│  the easy requests really are easy.                                          │
│                                                                              │

╭─ 5 of 7 · Full cost ─────────────────────────────────────────────────────────╮
│                                                                              │
│  Token price is only part of the cost. Add the people who review and fix     │
│  answers, retries when an answer fails, and engineering time.                │
│  A cheaper model that needs more human fixing can cost more overall.         │
│                                                                              │
│  Example: A reviewer spending a few minutes fixing each bad draft can cost   │
│  more than all the tokens.                                                   │
│                                                                              │
│  Why a PM cares: Finance asks what the feature costs, not what a token       │
│  costs. Count the people too.                                                │
│                                                                              │

╭─ 6 of 7 · When not to use an LLM ────────────────────────────────────────────╮
│                                                                              │
│  A simple rule or a database lookup is cheaper and faster than any model,    │
│  and it can't make things up.                                                │
│  Use one when the task has a single exact answer you can look up or          │
│  compute.                                                                    │
│                                                                              │
│  Example: Checking that an order number has 10 digits, or looking up an      │
│  order's status, needs no model at all.                                      │
│                                                                              │
│  Why a PM cares: "We don't need an LLM for this part" cuts cost and removes  │
│  a way to be wrong.                                                          │
│                                                                              │

╭─ 7 of 7 · How to answer "it depends" ────────────────────────────────────────╮
│                                                                              │
│  "It depends" is a fine start but a weak answer.                             │
│  Start from the job: who uses it, how often it runs, and what a mistake      │
│  costs. Say what the choice depends on, then commit.                         │
│  Template: "I'd use X because Y. I'd switch to Z if W."                      │
│                                                                              │
│  Example: "I'd use Sonnet for drafting replies because quality matters and   │
│  volume is moderate. I'd route simple questions to Haiku once we've          │
│  measured that it handles them."                                             │
│                                                                              │
│  Why a PM cares: Your team needs a decision with conditions, not a survey    │
│  of options.                                                                 │
│                                                                              │
