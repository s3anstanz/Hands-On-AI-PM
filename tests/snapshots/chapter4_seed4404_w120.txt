╭─ 1 of 6 · What a hallucination is ───────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  A hallucination is an answer that is fluent and confident but false.                                                │
│  It might be a made-up fact, a wrong number, a quote nobody said, or a source that doesn't exist.                    │
│                                                                                                                      │
│  Example: Ask for sources and you may get a real-looking title, authors and year for a paper that was never          │
│  written.                                                                                                            │
│                                                                                                                      │
│  Why a PM cares: Users can't spot a hallucination by reading it, so your product has to catch it.                    │
│                                                                                                                      │

╭─ 2 of 6 · Why it happens ────────────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  The model writes text that is likely, not text that has been checked. It has no built-in fact-checker.              │
│  A wrong answer comes from the same probability bars as a right one (Chapter 1). Sometimes the most likely token is  │
│  simply wrong.                                                                                                       │
│                                                                                                                      │
│  Think of it like: a quiz contestant who always answers, in the same confident voice, even when guessing.            │
│                                                                                                                      │
│  Example: "Einstein failed math" is repeated so often that it sounds right. It isn't true.                           │
│                                                                                                                      │
│  Why a PM cares: No setting turns this off, so you design around it.                                                 │
│                                                                                                                      │

╭─ 3 of 6 · Common causes ─────────────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  • Missing context: the fact it needed wasn't in the prompt. It's a common cause in products, and the one you        │
│  control.                                                                                                            │
│  • Past the knowledge cutoff: events after the training data ends.                                                   │
│  • A rare fact: one the model saw only a few times.                                                                  │
│  • A loaded question: one that assumes an answer exists, like "Which study proves this?"                             │
│                                                                                                                      │
│  Example: A sales assistant has no price list in its prompt. Asked what the premium plan costs, it writes a typical  │
│  price, not yours.                                                                                                   │
│                                                                                                                      │
│  Why a PM cares: Check what you put in the prompt before you blame the model.                                        │
│                                                                                                                      │

╭─ 4 of 6 · Why it sounds so sure ─────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  Tone isn't a confidence signal. The model writes as fluently when it's wrong as when it's right.                    │
│  It can't flag its own guesses unless the product is built to check.                                                 │
│                                                                                                                      │
│  Think of it like: a smooth salesperson who sounds the same whether the claim is true or not.                        │
│                                                                                                                      │
│  Why a PM cares: Users trust confident text, so your product has to supply the safeguards.                           │
│                                                                                                                      │

╭─ 5 of 6 · The fix toolbox ───────────────────────────────────────────────────────────────────────────────────────────╮
│                                                                                                                      │
│  1. Give it the facts. Grounding means putting the right documents in the prompt and telling the model to answer     │
│  only from them. Finding those documents first is retrieval (Chapter 7).                                             │
│  2. Let it say "I don't know" when the facts aren't there.                                                           │
│  3. Ask for citations, and check them.                                                                               │
│  4. Put a person in the loop when the stakes are high.                                                               │
│                                                                                                                      │
│  What doesn't work: temperature 0. It repeats the top answer, right or wrong.                                        │
│                                                                                                                      │
│  Example: A drug-information bot answers only from the label text it was given, cites the section, and says "not in  │
│  the label" otherwise.                                                                                               │
│                                                                                                                      │
│  Why a PM cares: These are product decisions, not model settings.                                                    │
│                                                                                                                      │

╭─ 6 of 6 · Why it matters more in healthcare, legal and finance ──────────────────────────────────────────────────────╮
│                                                                                                                      │
│  In some fields one wrong answer is costly: a patient harmed, a contract broken, money lost.                         │
│  The costlier one mistake is, the more safeguards you need and the more often a person checks.                       │
│                                                                                                                      │
│  Example: A clinical summary with the wrong dose looks as polished as a correct one.                                 │
│                                                                                                                      │
│  Why a PM cares: Set the bar by the cost of one mistake, not by average quality.                                     │
│                                                                                                                      │
